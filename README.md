# AutoQueue + AutoSignLFG

> **FRANÇAIS PLUS BAS**

***

## 🛠 Features

*   **Auto Accept:** Automatically confirms the role check when the party leader signs up for an activity, based on your current spec _(handles multi-role specs if needed)._
*   **Quick Signup:** Simply **__`double-click`__** a group to sign up instantly _`(Hold Shift + Double-click to add a note).`_
*   **Persistent Note:** Saves your note between signups _(persists until a /reload or reconnect)._
*   **Visual Cue:** Displays groups that <span style="color: #e03e2d;">declined </span> you in red and <span style="color: #e67e23;">re-listed</span> groups in orange, allowing you to sign up again !
*   **Minimap Button:** Includes a simple minimap icon to toggle the feature on/off.

**Available in all game languages!**

 

***

## 💻 Slash Commands

| Command     |Action                          |
| ----------- |------------------------------- |
| <code>/aq on</code> |Turn on AutoQueue               |
| <code>/aq off</code> |Turn off AutoQueue              |
| <code>/aq minimap</code> |Hide or Show the minimap button |

# AutoQueue + AutoSignLFG

***

## 🛠 Fonctionnalités

*   **Acceptation automatique :** Valide automatiquement la vérification de rôle lorsque le chef de groupe s'inscrit à une activité, selon votre spé actuelle _(avec gestion du multi-rôle si besoin)_.
*   **Inscription rapide :** Un simple **`double-clic`** sur un groupe pour s'y inscrire instantanément _`(faites Maj + double-clic pour ajouter une note).`_
*   **Note persistante :** Garde votre note en mémoire d'une inscription à l'autre. _(jusqu'au /reload ou reconnexion)_
*   **Repérage visuel :** Affiche en rouge les groupes qui vous ont <span style="color: #e03e2d;">refusé </span> et en orange ceux qui ont été <span style="color: #e67e23;">réinscrit</span>, vous permettant de vous y réinscrire !
*   **Bouton de minimap :** Inclut une icône simple sur la minimap pour activer/désactiver la fonctionnalité.

**Dispo dans toutes les langues du jeu !**

***
