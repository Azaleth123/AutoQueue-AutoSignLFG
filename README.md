# AutoQueue + AutoSignLFG

**FRANÇAIS PLUS BAS**

I combined 2 WeakAuras into a standalone addon, since WeakAuras no longer works.

**🚀 WORKS ON MIDNIGHT!**

***

## 🛠 Features

### AutoQueue

*   **Automatic Accept:** Automatically clicks the **"Accept"** button when your group leader signs up for an activity.
*   **Auto Role:** Automatically confirms your role based on your current specialization. (DPS, heal, tank)  
    (e.g. if you are in a healing spec, it will sign you in a healing role. If you switch to dps, it will sign you in a dps role, without needing to turn off the addon).
*   **Multi-Roles:** `Right-click` the minimap icon to queue for multiple roles or a different spec. If no selection is made, your current spec applies. Settings are saved per character.
*   **Persistent note:** Your note will be saved between different queues. _(To include a note, hold `Shift` and double-click to queue via the standard method.)_
*   **Minimap Button:** Includes a simple minimap icon to toggle the feature on/off, allowing you to switch roles or preferences easily.

### AutoSignLFG

*   **Quick Sign-up:** Automatically sign up in LFG with a simple **double-click**.
*   **Safe Mode:** To sign up the traditional way, just hold `Shift` + double-click (or `Shift` + click on "Sign Up").
*   **Toggleable:** Use `/lfg off` if you want to disable this specific feature.

***

## 💻 Slash Commands

| Command     |Action                                              |
| ----------- |--------------------------------------------------- |
| <code>/aq on</code> |Turn on AutoQueue                                   |
| <code>/aq off</code> |Turn off AutoQueue                                  |
| <code>/aq minimap</code> |Hide or Show the minimap button                     |
| <code>/lfg on</code> |Turn on AutoSignLFG                                 |
| <code>/lfg off</code> |Turn off AutoSignLFG                                |
| <code>/aq roles</code> |Show roles options OR right-click on minimap button |

# AutoQueue + AutoSignLFG

J'ai combiné 2 WeakAuras en un addon autonome, étant donné que WeakAuras ne fonctionne plus.

**🚀 COMPATIBLE AVEC MIDNIGHT !**

***

## 🛠 Fonctionnalités

### AutoQueue

*   **Acceptation automatique :** Clique automatiquement sur le bouton **"Accepter"** lorsque le chef de groupe s'inscrit à une activité.
*   **Rôle automatique :** Confirme automatiquement votre rôle en fonction de votre spécialisation actuelle (DPS, heal, tank).  
    (Par exemple, si vous êtes en spé heal, il vous inscrit en tant que heal. Si vous passez en DPS, il vous inscrit en DPS, sans avoir besoin de désactiver l'addon.)
*   **Multi-rôles :** Faites un `clic droit` sur l'icône de la minicarte pour vous inscrire dans plusieurs rôles ou avec une spécialisation différente. Si aucune sélection n'est faite, votre spé actuelle s'applique. Les paramètres sont sauvegardés par personnage.
*   **Note persistante :** Votre note sera sauvegardée entre les différentes files d'attente. _(Pour inclure une note, maintenez `Maj` et double-cliquez pour vous inscrire via la méthode classique.)_
*   **Bouton de minimap :** Inclut une icône simple sur la minimap pour activer/désactiver la fonctionnalité, permettant de changer de rôle ou de préférences facilement.

### AutoSignLFG

*   **Inscription rapide :** S'inscrit automatiquement dans le LFG d'un simple **double-clic**.
*   **Mode sécurisé :** Pour s'inscrire de manière traditionnelle, maintenez simplement `Maj` + double-clic (ou `Maj` + clic sur « S'inscrire »).
*   **Désactivable :** Utilisez `/lfg off` si vous souhaitez désactiver cette fonctionnalité spécifique.
